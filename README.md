# NexMind — AI Learning Platform

NexMind is a responsive front-end learning platform designed to help students explore and learn **Artificial Intelligence, Data Science, Machine Learning, Generative AI, and Python for AI**.

🌐 **Live Demo:** https://anuragdhobale.github.io/Nexmind/

## ✨ Features

- 🧠 AI-focused learning platform landing page
- 📚 Course catalogue for:
  - Python for AI
  - Machine Learning
  - Generative AI
  - Data Science
- 🗺️ AI career roadmap
- 📊 Student dashboard UI
- 🏆 Certificate generation interface
- 💳 Pricing page
- 📩 Contact page
- 💾 Browser-side progress/certificate data using `localStorage`
- 📱 Responsive front-end design

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**

## 🚀 Run Locally

No build tool is required.

1. Clone the repository:

```bash
git clone https://github.com/anuragdhobale/Nexmind.git
cd Nexmind
```

2. Open `index.html` in a browser.

For a better local development experience, use VS Code with the **Live Server** extension.

## 🌐 Deployment

The project is deployed using **GitHub Pages** from the `main` branch and the repository root.

Every commit pushed to `main` can trigger a new GitHub Pages deployment.

## ⚠️ Current Scope

NexMind is currently a **front-end/static web project**. Features such as authentication, payments, server-side course storage, and real AI/API integration would require a backend or external services.
