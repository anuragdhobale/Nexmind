Data Science Fundamentals

Data Science combines statistics, programming and domain knowledge to extract useful insights from data.

What is Data Science?

Data Science is an interdisciplinary field that uses scientific methods, statistics, programming and analytical techniques to extract meaningful information from data.

Data scientists work with raw information, transform it into useful datasets and use analysis to answer business and technical questions.

Data Science Process

Data Collection

Gather data from databases, APIs and other sources.

Data Cleaning

Fix missing, duplicate and inconsistent data.

Data Analysis

Discover patterns and generate useful insights.

Your First Data Analysis 

import pandas as pd

data = pd.read_csv("students.csv")

print(data.head())

print(data.describe())

Pandas can load a dataset and provide useful statistical summaries with just a few lines of Python.

Key Takeaways

  • Data Science extracts insights from data.
  • Statistics is an important part of Data Science.
  • Python is widely used for data analysis.
  • Data cleaning and exploration are essential steps.
